3.1 В процессе разработки были использованы две модели: ChatGPT и Codex
ChatGPT был использован для быстрого поиска какой-либо документации по библиотекам или же конкретных пунктов внутри документации
Codex использовался для написания шаблонных мест в коде, рефакторе кода, написания тестов и для дебага
Например, в ChatGPT были такие запросы:
-Как создать миграцию в Alembic?
-Как валидировать данные с помощью Pydantic?
-Какие параметры можно использовать при получении подключения в SQLite?
Пример запросов для Codex:
-Сделай доменные ошибки более подробными
-Сделай пример .env.example
-Напиши скрипт для того, чтобы делать пользователя админом
-Расскажи как зарефакторить этот файл для улучшения архитектуры

3.2 ИИ оказался наиболее полезен в самом начале и конце проекта. В начале проекта он был полезен для получения советов по архитектуре и документации. В середине написание большинства кода шла вручную (для уменьшения кол-ва ошибок). В конце же ИИ помог довести проект до более приемлимого вида.

Например, ИИ помог в моментах с построением структуры некоторых частей кода. Или же помог написать тесты для кода. 
В пример ошибки ИИ можно занести некоторые ошибки, которые не ломали работу сайта, но при этом нарушали логику его работы. Например, были моменты, когда он предлагал выбрасывать ошибку там, где это по факту не нужно. 
В некоторых ситуациях я отказывался от решений ИИ, т.к. логика файла была перегружена. Он пытался написать слишком сложный код там, где это не нужно. Или же, писал код, который портил структуру проекта (мешал логику и функционал разных слоёв в одном файле, писал импорты прямо внутри функции)

 Вывод: ИИ может значительно ускорить написание шаблонного кода или построение начальной архитектуры проекта, но в каких-то сложных местах его использовать не стоит, т.к. иногда он может написать неккоректный код, который может запускаться, но иметь в себе скрытые ошибки. 
 Я могу порекомендовать всегда перепроверять код от ИИ, т.к. иногда ошибки бывают даже в относительно простых местах. Хотя, Codex (и другие агенты именно для кода) и умеют запускать тесты, иногда тесты могут не покрывать некоторые тонкости, либо же ИИ может неверно интерпретировать результат тестов.
